# yeswanthchinta.github.io

Single-page career site. All content lives in `index.html`, with sections `#home`, `#about`, `#experience`, `#projects`, `#contact` — the nav scrolls smoothly between them and highlights the active section as you scroll.

Styling: `css/style.css`. Behavior (mobile menu + scroll-based nav highlighting): `js/main.js`.

`about.html`, `experience.html`, `projects.html`, `contact.html` are redirect stubs (in case anything had them bookmarked) — they just forward to the matching section in `index.html`.
